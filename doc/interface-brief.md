# Interface Brief — 潮痕之城

## Experience frame

- 异步进入同一城市的陌生旅人；正常玩家不看到工程诊断工具。
- 主循环：阅读区域背景和前人潮痕 → 选择快捷行动或自由输入 → 世界服务提交 → 后来者读到变化。
- 主状态：加载、空区域、有效潮痕、痕迹详情、公共援助、季节工程、永久锚点、错误恢复。

## Primary journey

1. 进入灯塔区，首屏直接读区域背景和当前世界事件。
2. 在对话流里读最多 6 条有效潮痕。
3. 点击潮痕查看寿命、数值效果、回应与领取操作。
4. 用底部快捷行动或 120 字自由输入提交一次改变。
5. 通过“世界”抽屉切换区域、参与本季工程或回看永久锚点。
6. 世界保持开放；没有五轮终止或强制重开。

## Information hierarchy

1. 当前区域正在发生什么。
2. 其他玩家留下了什么、还能持续多久。
3. 玩家现在能做什么。
4. 季节工程如何被多人推进。
5. 哪些改变已经跨季节成为历史。

## Error and recovery

- 版本冲突：Gateway 拉取最新快照，以同一 `action_id` 最多重试 3 次。
- 重复 action：服务端返回首次结果，不重复增加版本。
- 访客：可以读，写入时返回 `AUTH_REQUIRED`。
- 物资被抢完/痕迹过期：保留当前页面并显示世界内提示。
- 远端失败：不伪造写入成功；本地模式仍可用于离线机制测试。

## Direction lock

采用 `doc/visual.md` 的“同一对话结构、潮汐配色微调”。早期仪表盘结构已否决，不再作为产品方向。
