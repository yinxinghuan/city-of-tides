# 《潮痕之城》视觉方向

## 1. 视觉命题

一座会替互不相遇的人保存迟到对话的潮汐城市：公共痕迹应像自然进入叙事的城市记忆，而不是社交信息流或管理后台。

## 2. 构图与界面结构

- 体验框架为“入口封面 → 顶部城市状态 → 中部单列阅读流 → 底部行动区”。
- 阅读顺序固定为“世界背景 → 当前区域 → 永久锚点/季节工程 → 他人潮痕 → 玩家行动”。
- 世界抽屉容纳区域、个人行囊、季节工程和锚点；痕迹详情在移动端使用 bottom sheet，桌面端使用居中 modal。
- 主验收尺寸为 320×568、390×844、1024×768、1440×900；桌面最大宽度 900 px。

## 3. 色彩系统

- `--ct-night: #071216`：页面外部背景。
- `--ct-ink: #0e2025`：头部、行动区、抽屉。
- `--ct-paper: #e8e3d5`：故事和潮痕阅读面。
- `--ct-text: #252c2d`：纸面正文。
- `--ct-sea: #75a79b`、`--ct-sea-deep: #477a72`：潮水、同步和本人行动。
- `--ct-copper: #c18b61`：永久改变。
- `--ct-lamp: #e8c47e`：可行动目标与进度完成。
- `--ct-warning: #c96f5b`：风险和错误。

## 4. 排版系统

- 标题与叙事正文使用系统可用衬线字体；控件、数值和元信息使用系统无衬线字体。
- 正文支持 15/16/18 px 三档，叙事标题与正文同比调整。
- 数值使用 tabular numerals；小型大写标签只承担层级提示，不连续书写长句。

## 5. 形状、材质与光线

- 深海蓝硬边外壳稳定结构，冷灰纸面承担长文阅读，雾绿气泡区分本人行动。
- 临时痕迹使用浅色卡；永久锚点使用旧铜左边和锚图标；季节工程仅以克制进度条进入对话。
- 阴影保持低对比，避免玻璃拟态、霓虹发光和后台卡片堆叠感。

## 6. 素材规则

- 入口使用正式英文 `CITY OF TIDES` 海报，保持正方形完整构图，不裁成横幅。
- 他人玩家必须显示真实圆形头像和姓名；头像为空时使用姓名首字母，不显示空圆。
- 本人痕迹显示“你 / YOU”，不重复自己的头像。
- 不使用与潮汐城市无关的荒原、公路、邮戳、羊皮卷或通用 AI 奇幻图。

## 7. UI 与图标

- 功能图标统一使用 `src/shared-world/icons.tsx` 的单线 SVG 系统，禁止 Emoji 充当按钮或状态图标。
- 头像与姓名作为一个可点击身份组，平台内打开对应 Aigram 资料；本人身份不跳转。
- 核心按钮触控目标至少 44×44 CSS px；滚动列表和横向快捷行动使用 `onClick`。
- 普通行动一次点击提交；仅留言和回应展开 120 字输入区。

## 8. 动效与声音反馈

- 进入区域、写下潮痕、回应/贡献、锚定/结算和警告分别使用需求文档定义的程序化音色。
- 提交后同帧显示 busy 或内联结果，不等待轮询才反馈。
- 抽屉与详情只使用短距离位移和淡入；避免庆典粒子、无限呼吸光或让阅读位置漂移的装饰动画。
- `prefers-reduced-motion` 下去除非必要位移，保留状态变化。

## 9. 参考原则转译

- 借用即时通信的阅读熟悉度，但不复制聊天软件皮肤：区域叙事和城市事件始终高于社交身份。
- 借用档案馆的纸张、铜件和编号感，但不做复古道具拟真。
- 借用潮水的周期与消退语义，让 TTL、季节工程和永久锚点在视觉上形成“短暂 → 加固 → 留存”的层级。

## 10. 禁止项

- 禁止默认进入个人单人冒险或让多人能力只存在于未接入代码中。
- 禁止把共享世界改成实时房间、同步战斗、群聊墙或数据仪表盘。
- 禁止将外部访客栏高度写入平台内构图；platform-layout 仍按无访客栏验收。
- 禁止姓名无头像、头像无资料跳转、滚动项使用 `onPointerDown`、Emoji 功能图标。
- 禁止因桌面宽屏拆成复杂双栏后台；所有尺寸保持同一阅读顺序。

## 11. 纵切片验收

- 默认入口渲染 `.ct-stage` / `.ct-shell` 共享世界外壳，不包含个人冒险 `StoryShell`。
- 正式构建连接永久 session ID API；MiniAPP、正式主站与 Pages 镜像读取同一个 `world_key=main`。
- 320×568、390×844、1024×768 无横向溢出；platform-layout 是主验收，external-guest 只检查覆盖后仍可使用。
- 玩家可读取他人痕迹、打开他人资料、留下行动、领取有限援助、贡献季节工程并查看永久锚点。
- 入口、世界抽屉、痕迹详情、举报状态和个人行囊均有真实运行证据。

## 连续性呈现（2026-08-13）

- 正式共享世界的跨区域切换使用全屏 `.ct-transit` 中转页：深海遮罩、铜色顶线、地图到锚点的细线图形、出发区与目的区并列。它代表所有区域共用的“渡口潮图台”，不是通用加载弹窗。
- 中转页必须先于 `selectedRegionId` 更新出现；玩家确认潮位后才抵达目的区。取消则留在原区域，禁止背景先偷偷切换。
- 快捷行动区直接呈现当前区域已解释的动作，不常驻“请做出选择”，也不让按钮首次介绍陌生剧情名词。
