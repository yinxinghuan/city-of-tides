# 《潮痕之城》视觉方向

## 1. 体验框架

- 玩家：在不同时间进入同一座城市的 AlterU 用户，不需要组队或同时在线。
- 核心动作：读前人的潮痕，理解其效果，再给后来者留下一次行动。
- 情绪承诺：城市替互不相遇的人保存一段迟到的对话。
- 主验收尺寸：320×568、390×844、1024×768、1440×900。

## 2. 选定方向：潮汐城市档案

沿用已验证的对话式叙事模板，只把配色和事件语义换成《潮痕之城》：

1. 深海蓝头部与底部行动区负责稳定结构。
2. 冷灰纸色对话区负责长文本阅读。
3. 氧化铜、雾绿和少量琥珀只标记世界变化、公共工程与永久锚点。

不另造地图主屏、侧栏仪表盘或社交墙。三层共享世界机制进入对话流或“世界”抽屉，不改变主信息架构。

## 3. 色彩与材质

- `--ct-night: #071216`：页面外部背景。
- `--ct-ink: #0e2025`：头部、行动区、抽屉。
- `--ct-paper: #e8e3d5`：故事和潮痕阅读面。
- `--ct-text: #252c2d`：纸面正文。
- `--ct-sea: #75a79b`、`--ct-sea-deep: #477a72`：潮水、同步和本人行动。
- `--ct-copper: #c18b61`：永久改变。
- `--ct-lamp: #e8c47e`：可行动目标与进度完成。
- `--ct-warning: #c96f5b`：风险和错误。

禁止暖色荒原、公路、旅行邮戳、羊皮卷、无意义霓虹和《荒野之路》的任何场景资源。

## 4. 排版与图标

- 标题与叙事正文使用系统可用衬线字体；控件、数值和元信息使用系统无衬线字体。
- 正文由文字大小控件在 15/16/18 px 三档切换，叙事标题和正文同比调整。
- 数值使用 tabular numerals。
- 全部功能图标使用同一套单线 SVG；禁止 Emoji 作为功能图标。

## 5. 实际信息结构

1. 入口：正式英文封面、游戏一句话承诺和两段世界背景；玩家主动进入后才显示主界面。
2. 顶部：城市名、区域与潮汐季、3 个数值进度条、文字/语言/声音/世界入口。
3. 中部：单一滚动阅读流，严格按“世界背景 → 当前区域 → 他人痕迹”排列；永久锚点与季节工程属于当前区域信息。
4. 底部：标题为“你的行动”的自适应快捷行动；普通行动单击即提交，只有留言或回应时展开 120 字输入区。
5. 世界抽屉：区域、个人行囊、季节工程、永久锚点；`?lab=1` 才显示实验控制。行囊只呈现已经写入个人存档的物品与同步状态，不另造背包主屏。
6. 痕迹详情：移动端底部 sheet，桌面端居中 modal；他人痕迹提供单线旗帜举报入口。

## 6. 痕迹表现

- 他人痕迹为浅色卡；头像与姓名成组显示，平台内可进入资料页。
- 本人行动为雾绿气泡，仅显示“你”，不重复头像。
- 临时痕迹显示剩余时间；公共援助额外显示可领取份数。
- 公共援助写入个人存档后，在行囊页以单线箱体图标、物品名、数量和“已保存/同步中”状态展示；同步未完成不能伪装成已到账。
- 季节工程在对话中显示轻量进度事件，在“世界”抽屉里显示完整贡献入口。
- 永久锚点采用铜色左边和锚图标，可同时出现在对话事件与历史列表。
- 举报成功使用既有内联通知反馈；不增加独立治理后台或常驻警告栏。

## 7. 响应式合同

- 入口在桌面为封面与背景双栏，在移动端改为纵向；封面保持正方形完整构图，不强裁为横幅。
- Shell 单列使用 `grid-template-columns: minmax(0,1fr)`，避免 header/composer 的最小内容宽度撑出视口。
- 720 px 以下占满 `100dvh`；4 个顶部工具全部保留 40–44 px 触控区域。
- 快捷行动横向滚动，按钮宽度随文字内容变化，范围约 132–310 px。
- 桌面仍是同一对话结构，只增加阅读留白，不切成双栏后台。
- platform-layout 为主验收；external guest 仅检查访客栏覆盖后仍可使用。

## 8. 验收结论（2026-08-06）

- 2026-08-07 交互外壳复验：`interaction-final-platform-layout-entry-*` 与 `initial-*` 覆盖 320、390、1024、1440；`one-click-action-390x844`、`composer-390x844` 分别确认普通行动即时提交与留言专用输入。进入后的 `.ct-conversation.scrollTop === 0` 由 `_qa/interaction-shell.mjs` 自动断言。
- `conversation-approved-*` 截图覆盖 320、390、1024、1440、世界抽屉、援助详情、季节完成、永久锚点、远端 Gateway 和 external guest。
- 320/390 的 `scrollWidth === viewport`，世界按钮右边界分别为 307/377，均在视口内。
- 第一版仪表盘方向已被用户否定，仅作为 `_qa/ui/first-pass-*` 和 `recheck-*` 的失败证据保留。
- `grant-pack-saved-platform-layout-*` 覆盖 320×568、390×844、1024×768 的已到账行囊；`grant-pack-permission-platform-layout-390x844.png` 覆盖只读/实验身份说明。四个状态均无横向页面溢出，行囊复用现有抽屉而未增加主界面复杂度。
- 正式海报由 Aigram transit 生图接口生成；仅含英文标题 `CITY OF TIDES`，1024×1024 与 160×160 均已目视检查，来源记录见 `doc/poster-provenance.md`。
