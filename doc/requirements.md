# 《潮痕之城 / City of Tides》需求文档

> 2026-08-12 文字版 RPG 改造实验：保留累积阅读与自由探索，不改成固定电影舞台。开场三种行动由本地领域层结算，分别留下路线、救人或观察事实及不同数值后果；关键事实进入存档，重复领取被拒，未匹配的自由行动仍交给 AI。

## 1. Overview

《潮痕之城》是一个对话式异步共享世界：互不同时在线的玩家进入同一座周期性涨潮的城市，读取前人留下的短期痕迹、共同推进一季工程，并让少量成果跨季节成为永久锚点。

首版不做实时联机、组队或同步战斗；大语言模型可以补充叙述，但不能直接决定公共数值或写数据库。MiniAPP 与 UUID 正式主站进入同一个异步共享世界；GitHub Pages 仅保留同 commit 的静态构建/源码镜像，不作为共享世界运行时。

## 2. Visual Design

- 首次进入先显示正式封面与世界背景介绍；玩家主动进入城市后，从正文开头开始阅读，不自动跳到对话底部。
- 使用“顶部状态—中部对话流—底部行动”的单列结构，以深海蓝、雾绿、旧铜和冷灰纸色形成题材差异。
- 主阅读顺序固定为“世界背景 → 当前区域 → 他人痕迹 → 你的行动”，多人机制不能打乱叙事层级。
- 当前区域最多显示 6 条有效潮痕；他人身份显示头像与姓名，平台内可打开个人资料。
- 区域、个人行囊、季节工程和永久锚点进入“世界”抽屉，不另做后台式仪表盘。
- 320×568、390×844、1024×768、1440×900 均保持同一单列结构；桌面 Shell 最大宽度 900 px。
- 正文三档为 15/16/18 px；触控目标 40–44 px，核心目标至少 44 px；功能图标统一为 SVG。
- 详细系统见 `doc/visual.md`。

## 3. Game Mechanics

### 3.1 四个区域与数值

- 灯塔区初始 42、沉水车站 38、雨棚市场 46、钟楼档案馆 35。
- 状态分段：0–19 被淹没、20–44 脆弱、45–84 恢复中、85–100 本季复苏。
- 修复 `+12×强度`，公共援助 `+8×强度`，安全路线 `+10×强度`；留言与警告主要传递信息。
- 所有数值由确定性 reducer 重建并限制在 0–100；客户端不能提交计算结果。

### 3.2 即时潮痕

- 留言 48 小时、警告 72 小时、公共援助 96 小时、维修/路线 168 小时。
- 未锚定痕迹强度为 `1-age/lifetime`；过期后退出正常查询但保留审计事件。
- 每个区域正常界面最多 6 条有效痕迹；同一作者最多占 2 条。
- 公共援助默认 3 份；服务端原子扣减并生成领取回执，四人并发争抢最多三人成功。
- 真实玩家领取成功后，回执先按 `receipt_id` 幂等合并进个人行囊，再写入平台云存档；只有回读确认后才向共享世界确认完成。
- 三名不同玩家加固同一潮痕后，它在本季强度固定为 1。

### 3.3 潮汐季工程

- 一季固定 7×24 小时；服务器时间是唯一权威。跨过季节边界后的第一位访问者触发服务端惰性结算。
- 每个区域有一个 0–100 工程；每位用户每季对每个工程只能贡献一次，每次固定 +25。
- 工程达到 100 且至少有 3 位不同贡献者时，才成为永久锚点候选；同一季只结算一次。

### 3.4 永久锚点与治理

- 永久锚点只能由季节结算器根据已提交事件生成，普通客户端不能直接创建。
- 锚点保存区域、工程、贡献者、来源事件和创建时间，并跨季节保留。
- 每道他人潮痕都提供举报入口；同一用户对同一实体只记一次，三名不同用户举报后从公共快照和列表隐藏。

### 3.5 一致性与接口

- 世界真源为 Cloudflare Durable Object + SQLite；前端经 `SharedWorldGateway` 访问。
- `action_id` 全局幂等；`expected_version` 乐观并发；冲突后拉取最新状态并用同一 action 最多重试 3 次。
- 无 API 配置时本地 Gateway 使用四名模拟旅人；正式构建固定连接 session ID 对应的共享世界 API。
- 正式玩家只使用当前 Aigram 身份；`?lab=1` 才暴露四身份模拟和实验控制。

## 4. Controls

- Pointer/Touch：点消息看详情；普通快捷行动单击一次立即提交；只有“留言”与“回应”打开文字输入；点“世界”选择区域后先进入“渡口潮图台”中转确认，再抵达目标区域；同一抽屉还可查看个人行囊或参与工程。
- 横向快捷行动使用 `onClick` 并允许滚动，宽度约 132–310 px；不使用会抢滑动的 `onPointerDown`。
- 留言/回应最多 120 字且不能为空；普通行动使用对应默认文案直接提交。
- Keyboard：Tab 导航，Enter/Space 激活，Escape 关闭抽屉或详情，非输入态按 W 打开世界。
- zh/en 根据系统或 `game_locale` 自动选择，顶部可手动切换。
- 检测到个人进入记录时显示“继续游戏 / 重新开始”；重开只重置个人阅读位置，不删除公共世界、他人痕迹或个人行囊。

## 5. Win / Lose Conditions

游戏没有传统死亡、五轮终止或强制重开。

- 单次完成感：成功留下 1 条潮痕、回应他人、领取一份援助或为工程贡献 25 点。
- 区域阶段目标：达到 85 后进入“本季复苏”；低于 20 进入“被潮水吞没”，但仍可继续修复。
- 季节目标：工程达到 100 且满足至少 3 位不同贡献者的门槛，结算后生成永久锚点。
- 正常用户不能重置公共世界；只有 `?lab=1` 的实验环境提供二次确认重置。

## 6. Sound Effects

- 低干扰阅读门禁：普通选择最多播放一次轻确认；普通正文到达、图片完成和常规数值变化保持静音。只有检定、关系转折、危险阶段、地点抵达、公共回执或锚点完成等独立持久后果，才可在同回合稍后追加一次语义提示。故事合成 SFX 总线额外乘 `0.52`；共享世界短提示增益不高于 `0.024`，并在 `360 ms` 内合并重复触发。

- 首次有效手势后启动 Web Audio；声音失败或静音不阻塞行动。
- 切换区域：220–330 Hz 双音，约 90 ms，峰值增益 ≤0.035。
- 留下潮痕：440–660 Hz 上行三音，约 180 ms，峰值增益 ≤0.045。
- 回应/贡献：330 Hz 与 495 Hz 叠音，约 240 ms，峰值增益 ≤0.04。
- 锚定/季节结算：196–392–587 Hz 三层钟，约 650 ms，峰值增益 ≤0.055。
- 警告/拒绝：140 Hz 低频短噪与 220 Hz 衰减音，约 220 ms。
- 环境音由 Web Audio 程序化生成，不依赖外部音频文件；页面隐藏后暂停。

## 连续性门槛（2026-08-13）

- 正式共享世界入口从一个区域切换到另一个区域时，必须先经过所有区域共用的“渡口潮图台”：画面明确显示出发区、潮位确认和目的区，玩家确认后才真正改变区域。禁止点地图后直接把一个区域画面替换成另一个区域。
- 正式入口的快捷行动只使用当前区域已解释的通用动作（留言、警告、援助、维修、路线），不允许靠按钮首次引入陌生人物、机构或任务前提；也不显示“请做出选择”“接下来怎么办”等重复提示。
- 仓库内未发布的个人冒险研究引擎另以“逆潮罗盘与随身潮汐航图”处理其地图跳转和生成选项接地，不得将研究代码的测试结果冒充正式入口验收。
- 该研究引擎的累积阅读模式不复述正文；只有必要的独立短局面才显示“眼前”。模型不得打印状态清单，数值由协议提交后用增减签条和顶部单项约 `860 ms` 动态反馈表达。

## 推荐选项与镜头导演升级（2026-08-17）

- 个人冒险研究引擎对生成选项逐条做连续性检查：保留所有成立的选项，只删除断头路，不再因为一条坏选项抛弃整组，也不为凑满三条补入无关行动；每回合允许 `1–5` 条有效选项。
- 危险未解决时，兜底选项必须继续处理同一具体威胁，并使用 cartridge 已声明的单步应对手段；没有危险且所有推荐都失效时，不补通用选项，保留自由输入。
- 场景图按每种语言连续 20 个普通回合精确保持第一人称与第三人称 `10:10`。重要对话优先第一人称，新地点建立镜头与玩家可见的完整动作使用第三人称。
- 第一人称图不传玩家形象参考，也不生成主角身体、越肩或凭空出现的手；第三人称图只有在主角确实入镜时才使用玩家形象参考。
- 正式多人世界仍只以 UUID 主站同 Worker 后端为权威；Pages 只镜像同提交静态前端，不连接源游戏数据库。
