# 《潮痕之城 / City of Tides》v2 需求文档

## 1. Overview

《潮痕之城》是一款有明确主线的开放世界 AI 冒险：玩家作为阔别故乡七年的归乡者，自由探索一座随潮位改变道路的海港，在第七次大潮前追查姐姐米拉与另外四十六名失踪者，并通过人物关系、物品和区域选择决定城市结局。

首个可发布纵切片覆盖约 15–25 分钟：返乡渡船、第一次自由行动、一次潮相变化、认识尼洛、听见米拉第一道回声、登上高处选择四个区域。关闭全部多人数据后，纵切片必须完整成立。

## 2. Visual Design

- 保留现有“顶部状态—中部叙事流—底部行动”的舒适单列外壳，但第一视觉焦点从公共数据改为当前冒险场景。
- 入口使用原生横向返乡场景，不使用正方形海报强裁；正文图片内联在触发它的事件处，生成中不抢滚动位置。
- 视觉身份为“电影感海港奇幻冒险”：深青海水、氧化铜、雾白天空、温暖室内灯光和纪念碑式半淹建筑。
- 主角场景图在平台内优先引用当前用户头像；物品图只继承画风，不引用头像或封面构图。
- 主 UI 只持续显示三个数值、所在地、潮相与当前目标；人物、地图、行囊、旅记进入“世界”抽屉。
- 共享玩家痕迹不在本纵切片主界面占位。后续接入时只作为当前场景中可忽略的发现，最多六条。
- 支持 zh/en，正文移动端不低于 16 px，文字大小提供 15/16/18 px 三档；正式平台海报仍只允许英文。
- 目标视口为 320×568、390×844、1024×768、1440×900；桌面最大阅读宽度约 900 px。

完整系统见 `doc/visual.md`。

## 3. Game Mechanics

### 3.1 个人世界真源

- `StorySave` 保存地点、时间、当前目标、三项数值、叙事时间线、当前行动、地图、物品、角色、队伍与关系事件。
- AI 每轮接收受裁剪的权威状态和相关历史，只能提出结构化改变；确定性 reducer 校验并提交。
- 每轮至少改变地点、时间、目标、数值、物品、人物关系或已知事实中的一项；不能连续只写气氛。
- 建议按钮与可见正文必须描述同一局面；没有可信具体选项时不伪造“继续这段旅程”。

### 3.2 三个可见数值

- 体力：0–100，初始 72；单轮最大变化 24。低于 25 进入警告，降到 0 后在最近安全地点恢复，不删除存档。
- 潮息：0–100，初始 40；单轮最大变化 25。读取强回声和驱动潮铜装置消耗，低于 20 警告；归零后仍可用普通方式行动。
- 城市联结：0–100，初始 10；单轮最大变化 18。履行承诺、帮助人物和连接区域提高，开启协作路线并影响结局。

### 3.3 世界规则

- 城市每日两次低潮和两次高潮；长距离移动、等待、休息或重大行动推进可见时间和潮相。
- 低潮开放街道、地窖、礁洞和轨道；高潮开放水路、屋顶码头、漂浮设施和上升气流。
- 强烈言语或行动第一次被海水淹没时，在潮铜或潮石上保留最多七个潮相的回声。
- 人物只知道自己亲历、听说或读到的事实；同伴不会在遇到新 NPC 后消失，物品归属和已确认后果不能静默改写。
- 主线由故事节点推进，不设五轮结束和现实倒计时；玩家可以拒绝所有建议路线并自由描述合理行动。

### 3.4 纵切片状态

1. 未进入：封面、承诺、背景钩子与进入按钮。
2. 恢复存档：已有进度时提供“继续游戏 / 重新开始”；继续滚动到最新行动，重开二次确认。
3. 返乡渡船：四种可行意图为追退潮旧路、救落水者、询问船夫、登高观察；UI 显示三条建议和自由输入。
4. 潮相变化：至少一次路径变化，产生即时视觉、音效和状态反馈。
5. 尼洛相识：可以邀请、拒绝或暂不决定；人物继续留在世界状态中。
6. 米拉回声：产生一张内联剧情图和目标更新。
7. 高点选择：灯塔区、沉水车站、雨棚市场、钟楼档案馆四个目的地进入地图；这是可继续的章节边界，不锁输入。

### 3.5 物品与视觉

- 初始物品为逆潮罗盘、折潮帆、密封灯芯，每件展示数量/稀有度、具体作用、限制、来源与可读指标。
- 第一次打开行囊时，物品图自动串行生成；用世界观文案说明“潮铜图谱正在显影”，不要求用户点击生成。
- 场景图采用“AI 提议＋本地导演兜底”：新地点、队伍变化和章节节点保证出图；普通回合连续最多 3 次无图。
- 一次回应最多决定一张场景图；图片只取当前场景和动作，禁止重复附加入口/封面构图。

### 3.6 异步共享层边界

- 现有共享世界 Worker、事件 reducer、限时潮痕、公共援助、季节工程和永久锚点代码与数据全部保留。
- 纵切片不依赖它们，不在个人主线中显示公共仪表盘。
- 后续接入只允许给当前场景追加最多六条可选痕迹、有限物品或临时路线；不能改变个人主线事实、同伴和结局条件。

## 4. Controls

- 触控/鼠标：普通建议行动单击一次立即提交；不再先选中再按提交。
- 自由行动：点“说说你想怎么做”展开输入，1–240 字，发送后即时显示本人行动气泡。
- 横向建议区允许滑动，按钮使用 `onClick` 并按文字自适应宽度 132–310 px。
- “世界”抽屉中的人物、地图、行囊和旅记行使用 `onClick`，支持滚动与详情展开。
- 键盘：Tab 导航，Enter/Space 激活，非输入态数字 1–3 选择建议，W 打开世界，Escape 关闭弹层。
- 行动发送后先在同帧出现本人的行动与加载反馈；LLM、图片、保存和统计均不阻塞第一层反馈。
- 首次进入从背景开头阅读；普通回应滚动到新文字阅读起点，不滚到尚未完成的图片锚点。

## 5. Win / Lose Conditions

- 纵切片完成条件：玩家听见米拉第一道真实回声并到达能选择四区的城市高点。完成后显示“城市已经向你展开”，保留输入和世界抽屉，可继续自由行动。
- 完整游戏有三类真实结局：封钟、开海、共潮；纵切片不提前结算。
- 体力归零不是死亡或删档：玩家在最近安全点醒来，推进一个潮相，恢复到 35，并失去最多一件未固定消耗品。
- 潮息归零只关闭回声/潮铜特殊选项，休息或物品可恢复。
- 行动失败产生受伤、物资损失、路线变化或人物不信任，但关键主线始终保留替代路径。
- 世界抽屉和恢复弹窗都提供二次确认的“重新开始”，只清除本游戏个人故事存档，不清除公共共享世界。

## 6. Sound Effects

- 首次有效手势后解锁 Web Audio；页面隐藏时暂停，失败或静音不阻塞游戏。
- 环境底层：64 BPM，低频海潮噪声 55–180 Hz、远钟正弦/三角波 196–392 Hz，主总线峰值 ≤0.18。
- 普通行动：潮铜轻敲 330→440 Hz，90–130 ms，峰值 ≤0.04。
- 状态变化：两音上行或下行 260–520 Hz，160–220 ms，正负结果音程方向不同。
- 新地点：风与钟三层进入，约 420 ms，峰值 ≤0.05。
- 米拉回声：稀疏钢琴/钟音 220、330、494 Hz，约 650 ms，避免恐怖跳吓。
- 受伤/危险：140 Hz 低频短噪与 196 Hz 衰减，180–260 ms，峰值 ≤0.045。
- 纵切片完成：196–293–440–587 Hz 四层钟，800 ms，峰值 ≤0.055。
