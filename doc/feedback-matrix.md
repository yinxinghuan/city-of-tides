# Feedback Matrix — 潮痕之城

| 事件 | 即时视觉 | 状态结果 | 声音 | 恢复 |
|---|---|---|---|---|
| 切换区域 | 抽屉关闭，对话切换 | 区域值与潮痕更新 | 水滴双音 | 保留新区域 |
| 选择行动 | 快捷按钮描边 | 输入语义切换 | 轻触音 | 可继续改选 |
| 提交潮痕 | 按钮进入 busy | 服务端版本 +1，新消息追加 | 上行三音 | 冲突自动同步重试 |
| 打开痕迹 | 详情 sheet/modal | 显示寿命、效果、加固 | 无 | 关闭回原位置 |
| 回应/加固 | 目标支持数增加 | 3 位不同用户后本季锚定 | 双层铃/三层钟 | action 幂等 |
| 领取援助 | 份数减少 | 3 份只能生成 3 张回执 | 短提示音 | 未确认回执可补偿 |
| 工程贡献 | 进度条 +25 | 同用户每季一次 | 双层铃 | 重复贡献被拒绝 |
| 季节结算 | 锚点进入历史 | 临时层换季，合规工程晋升 | 三层钟 | 同季只结算一次 |
| 访客写入 | 对话内提示 | `AUTH_REQUIRED` | 警告短音 | 登录后再写 |
| 限流/过期 | 保留当前输入和页面 | 不写世界版本 | 警告短音 | 稍后重试或刷新 |
