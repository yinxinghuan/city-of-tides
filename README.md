# City of Tides

An asynchronous shared-world experiment for AlterU. Travellers arriving at different times can leave expiring traces, share limited aid, reinforce useful messages, contribute to seasonal civic projects, and leave permanent anchors in the city’s history.

## Development

```bash
npm install
npm run dev
npm run build
```

The production frontend connects to `https://game.aiwaves.tech/city-of-tides`. Public shared-world writes are intentionally running as a bounded beta until AlterU exposes a signed identity proof that custom game Workers can verify.
